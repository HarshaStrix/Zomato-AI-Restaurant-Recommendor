# Zomato AI Restaurant Recommender

An intelligent restaurant recommendation system for Bangalore, powered by deterministic ranking and LLM-based explanations.

## Features
- **Smart Filtering**: Filter by location, cuisine, price range, and rating.
- **AI Explanations**: Personalized summaries and restaurant details generated by Groq LLM (Llama 3.1).
- **Natural Language Search**: Describe what you want in plain English, and the AI extracts the relevant filters.
- **Rich UI**: A premium, responsive interface designed for the best user experience.

## Getting Started

### Prerequisites
- Python 3.9+
- Node.js 18+
- Groq API Key

### Installation
1. Clone the repository
2. Set up the environment:
   ```bash
   cp .env.example .env  # Add your GROQ_API_KEY
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Run the application:
   - **Recommended (Full Stack)**:
     ```bash
     ./run-app.sh
     ```
   - **Streamlit Version (Quick Deployment)**:
     ```bash
     streamlit run streamlit_app.py
     ```
